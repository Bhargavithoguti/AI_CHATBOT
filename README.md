# AI Chatbot 🤖

An AI Chatbot web application that allows users to interact with an AI assistant through a user-friendly interface. The project includes user authentication, chat functionality, user profiles, and an admin dashboard.

## 🚀 Features

- User registration and login
- JWT-based authentication
- Protected routes
- AI-powered chat functionality
- User dashboard
- User profile page
- Dark mode support
- Admin dashboard
- MongoDB database integration
- Responsive frontend design

## 🛠️ Technologies Used

### Frontend

- React.js
- React Router DOM
- Tailwind CSS
- Zustand
- JavaScript
- Vite

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Google Gemini API
